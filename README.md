# Anything Launcher — дистрибуция

Сюда выкладываются **релизы с инсталляторами** лаунчера Anything Launcher
и тестовые манифесты сервер-пака. Исходный код — в приватном репозитории.

## Установка
1. Скачай `AnythingLauncher-Setup-X.Y.Z.exe` из последнего релиза справа.
2. Установи — лаунчер будет обновляться сам (проверка раз в 6 часов + баннер).

## Ссылка на сервер-пак
Пост в Discord → лаунчер создаст сборку и будет синхронизировать её сам.
